Рецепты sign-craze

Готовые сценарии конфигурации routing/firewall для типовых задач.

Все рецепты совместимы со всеми ядрами (v1.0.0+). Описанные шаги работают одинаково для sing-box, xray и mihomo — sign-craze автоматически транслирует правила из routing.json в нативный формат активного ядра. Если после смены ядра Validate показывает предупреждения — повторно примените пресет.

Рецепт Цель
Recipe-RU-Direct.md РФ-домены и IP идут direct, всё остальное через VPN

Быстрый старт через пресеты (v1.5.0+)

Часть рецептов доступна как встроенный routing-пресет — применяется одной командой прямо при --install (mode=replace, полностью перезаписывает Rules/Final):

sign-craze --install <url> --preset <name>

Список встроенных пресетов и их описания:

sign-craze --preset-list

Пресеты также доступны в web UI :9092 → вкладка Routing → «Пресеты ▾» → «Заменить» (TO-BE, очистить Rules + force-set Final) или «+ Добавить» (аддитивно, без сброса Final).

Структура рецепта

Каждый рецепт следует единому шаблону:

  • Цель — что решает рецепт и когда применимо.
  • Prerequisites — что должно быть настроено до начала.
  • Recipe A (UI) — пошаговый сценарий через WebUI :9092.
  • Recipe B (консоль) — те же шаги через REST API и SSH.
  • Verification — как убедиться, что всё работает.
  • Rollback — как отменить изменения.
